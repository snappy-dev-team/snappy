# 管理用マイページ (Admin) の使い方

## 役割
- 学生プラン希望のクライアントを承認/却下するための専用ページです。
- 個人マイページ側からは学生ステータスを変更できません。必ずこのページで行ってください。

## アクセス方法
- ローカル開発環境: `http://localhost:3000/admin`
- デプロイ環境: ルートURLに `/admin` を付けてアクセスしてください。
-  Basic認証が有効です。`ADMIN_BASIC_USER` / `ADMIN_BASIC_PASS` を環境変数で設定し、同じ値でアクセスしてください。

## 画面構成と操作
- 承認待ちの学生アカウント
  - 「有効化」で `approved` に更新
  - 「無効化」で `rejected` に更新
  - 「保留に戻す」で `pending` に戻す
- 処理済み学生アカウント
  - 現在のステータスを確認し、必要なら再度変更できます。
- サンプルデータ投入
  - 右上の「サンプルデータ投入」ボタンで users/jobs のデモデータを追加できます（動作確認用）。

## ステータスの意味
- `pending`: 管理者が確認中。学生向け募集は利用不可。
- `approved`: 学生アカウントとして有効。学生向け募集の作成が可能。
- `rejected`: 無効化された状態。学生向け募集は利用不可。

## 反映範囲
- 承認結果はユーザーのマイページにも反映され、`approved` のときのみ「仕事募集（学生）」が操作可能になります。
